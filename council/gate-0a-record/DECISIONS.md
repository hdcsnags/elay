## Astra verification outcome (2026-09-11, `docs/audits/elay/2026-09-11-gate0a-verification/astra.md`, confidence 0.94)

6 CONFIRM / 2 CHALLENGE-rationale-retain-choice (decisions 4, 5). **Web fact-check (Sonnet researcher, 2026-09-11) upheld Astra on both**: Nav3's `navigation3-ui` ships for iOS/desktop/web since CMP 1.10 (real caveat: explicit serialization wiring on non-JVM), and Expressive works in common code since CMP 1.9 but is experimental/alpha. Toolchain sheet corrected in place; ADR-004 rationale rewritten (classic nav = deliberate simplicity; Expressive excluded for maturity, not platform). Adopted from Astra: Room pinned at current release (3.0.3+, sheet stale); "identical SQLite" narrowed to "consistent engine, platform smoke tests still required"; free-runner claim qualified to *standard* hosted runners; iOS CI must link + launch + Room smoke, not just compile; DB CI on Linux; protected branch, checks on merged revision. Five missed risks adopted as contracts: field-level projection (→ ADR-007), recurrence gap/fold policy (→ ADR-006), offline-cache revocation (→ ADR-009), per-participant commitments + durable delivery jobs (→ ADR-010, ruling two §16 questions), stale AI confirmation envelopes (→ ADR-008). Sequencing accepted: contracts + ADR reconciliation BEFORE scaffold, then scaffold → CI → local Supabase harness → verified baseline → coder dispatch. Phase 0 gate commands to be re-derived from the actual scaffold's task graph (`gradlew projects` / `tasks --all`), requiring nonzero executed tests.

Failure modes + guardrails adopted (union of both seats): (1) RLS/Realtime leak → every migration ships grants + RLS + paired positive/negative pgTAP; adversarial REST/realtime tests at Gates 1–3. (2) Offline/concurrent time-lock corruption → single server-side transition RPC, expected_version, idempotency keys, append-only revisions, no optimistic terminal states. (3) iOS rot on a Windows-first build → per-PR simulator compile, thin SDK adapters, small expect/actual surface, no gate closes red. (4) Timezone drift → all conversions through kotlinx-datetime, DST test matrix (Vancouver/Toronto/UTC/Kolkata over spring-forward and fall-back), CI grep for hard-coded offsets. (5) Dependency desync → everything pinned in `libs.versions.toml`; coder seats may not edit build files without concierge approval.
